# Funeral Quiz Avatars

Place your avatar images in this folder. Name each image file according to the archetype below. Use PNG or SVG format for best results.

## Avatar Names & Descriptions

1. **peacefulSoul.png**
   - *"ผู้แสวงหาความสงบ" (The Peaceful Soul)*
   - Calm, serene, gentle. Suggest: a soft blue/green palette, peaceful nature, or a meditating figure.

2. **lifeCelebrator.png**
   - *"ผู้เฉลิมฉลองชีวิต" (The Life Celebrator)*
   - Joyful, vibrant, expressive. Suggest: warm colors, confetti, music notes, or a smiling character.

3. **legacyGiver.png**
   - *"ผู้สร้างมรดก" (The Legacy Giver)*
   - Thoughtful, inspiring, wise. Suggest: a book, tree, or a figure passing a light/torch.

4. **heartGuardian.png**
   - *"ผู้พิทักษ์หัวใจ" (The Heart Guardian)*
   - Caring, warm, family-oriented. Suggest: hearts, a hugging figure, or a gentle embrace.

5. **quietPhilosopher.png**
   - *"นักคิดเงียบ" (The Quiet Philosopher)*
   - Deep, contemplative, spiritual. Suggest: a starry sky, candle, or a figure looking at the moon.

**How to use:**
- Place your avatar images in this folder.
- Name each file exactly as above (e.g., `peacefulSoul.png`).
- The app will display the correct avatar based on the user's quiz result.
